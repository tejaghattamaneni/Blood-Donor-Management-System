# 🩸 Blood Donor Management System

A **Flask-based web application** that allows users to register as blood donors and search for available donors based on **location** and **blood group**.  

This project demonstrates **full-stack Python development** with **Flask, SQLAlchemy, SQLite, Bootstrap, and HTML/CSS**.

---

## 🚀 Features
- Donor registration with validation (Name, Blood Group, Mobile, Location).
- Search donors by **location and blood group**.
- Display results in a **responsive Bootstrap table**.
- **Session management**: only registered users can access the search page.
- Backend powered by **Flask + SQLAlchemy** with **SQLite database**.

---

## 🛠️ Tech Stack
- **Backend**: Python, Flask, SQLAlchemy  
- **Database**: SQLite  
- **Frontend**: HTML, CSS, Bootstrap  
- **Tools**: Flask-SQLAlchemy, Jinja2 templating
